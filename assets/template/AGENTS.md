## Project rules for agents

Read these before any task. They are binding.

| File | Read when | Tells you |
|---|---|---|
| `docs/context/ai-workflow-rules.md` | Every task | How to work |
| `docs/context/project-overview.md` | Every task | What to build and what not to build |
| `docs/context/architecture.md` | Every task | Which design pattern to follow and where files go |
| `docs/context/code-standards.md` | Any code change | How code must be written |
| `docs/context/git-workflow.md` | Any branch or commit | How to branch and commit |
| `docs/context/ui-context.md` | Any interface change | How interfaces must look and behave |
| `docs/progress-tracker.md` | Start and end of task | Current state of the project |

If a task conflicts with these files, stop and ask. If existing code conflicts with them, follow the files and report the conflict.
